# Jeux

## Bébé scutigère

Un jeu tout doux où l’on est la maman d’un bébé scutigère : soins, cache-cache, mémoire, conversations et anniversaires jusqu’à 18 ans.

Pour jouer, ouvrir **[bebe-scutigere/dist/index.html](bebe-scutigere/dist/index.html)** dans un navigateur.

Les règles et les commandes se trouvent dans le [README du jeu](bebe-scutigere/README.md).
