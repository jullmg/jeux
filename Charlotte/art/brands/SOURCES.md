# Brand artwork

Real brands and their logos are allowed in the game (Julien's decision, 2026-11-01). Each file here says where it comes from.
The logos and names belong to their owners; they appear in this personal game only to make the neighbourhood look real.
To add one: put the file here, add a row below, and stamp it on the drawn art with `ShopArt._stamped`.
