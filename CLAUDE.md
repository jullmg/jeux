# jeux

Small games, one per folder:

- `Charlotte/`: Godot 4 game. Its context is imported below.
- `bebe-scutigere/`: web game, see `bebe-scutigere/README.md`.
- `blanche-agente-du-chaos/`: Godot 4 3D game « Blanche Pronovost agente du Chaos » (a dog steals food while Mom cooks),
  see `blanche-agente-du-chaos/CLAUDE.md`.
- `utils/streetview/`: Python tool that takes Street View pictures of Charlotte's neighbourhood into
  `Charlotte/reference/streetview/` (with `INDEX.md`: address, position and game scene of each picture), see its README.
